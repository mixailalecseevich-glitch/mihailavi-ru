# Product specification

## Product

A single-page personal website for Mikhail Kosorubov that presents his digital services and sends interested visitors directly to a messenger.

## Target user

Small-business owners and independent specialists who need a website, Avito packaging, VK community design, advertising, or an audit.

## Problem

The existing site is narrowly focused on Avito, contains unsupported claims, and uses a contact form without a backend.

## Value proposition

One specialist can assemble the full online presentation of a business: website, marketplaces, social community, visual materials, advertising, and audit.

## Core journey

Open site -> understand services -> review real Kelo case -> choose messenger -> start conversation.

## P0

- Responsive single-page site.
- Six services.
- Real personal photography.
- Real Kelo case.
- Direct VK and Telegram links.
- No contact form.
- GitHub Pages deployment.

## P1

- Social sharing metadata.
- Accessible mobile navigation.
- Redirect legacy pages to relevant sections.
- Lightweight local assets and local font files.

## P2

- Custom domain after DNS access is available.
- Analytics after the correct counter ID is confirmed.

## Non-goals

- CRM integration.
- Lead forms.
- Backend or database.
- Online payment.
- Unsupported performance or revenue claims.

## Definition of done

The site builds without external application dependencies, works at desktop and mobile widths, exposes only verified copy, opens messenger links, and is available on the existing GitHub Pages URL.
