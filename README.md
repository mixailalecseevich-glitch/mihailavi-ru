# mihailavi.ru — Портфолио Авитолога

Современный сайт-портфолио для Михаила — специалиста по продвижению бизнеса на Авито.

## Структура сайта

- **index.html** — Главная страница (герой, услуги, процесс, результаты, отзывы)
- **services.html** — Услуги с подробным описанием (упаковка, реклама, стратегия)
- **niches.html** — 12 направлений с детализацией по каждой нише
- **results.html** — Кейсы и результаты с цифрами
- **contact.html** — Форма обратной связи и контакты

## Технологии

- HTML5, CSS3, Vanilla JavaScript
- CSS Custom Properties (дизайн-токены)
- Адаптивный дизайн (мобильный-first)
- Inter (Google Fonts)
- Lucide Icons
