# Михаил: сайты, Avito, VK и реклама

Персональный сайт-портфолио Михаила. Показывает состав услуг, примеры интерьеров и реальные кейсы. Контакт напрямую через Telegram или MAX, без формы заявки.

## Что есть на сайте

- сайт под ключ;
- ведение и оформление Avito;
- оформление сообществ и реклама VK;
- аудит интернет-упаковки;
- кейс со скриншотами сайта, сообщества и рекламного кабинета;
- адаптивные версии для компьютера и телефона;
- только прямые контакты в мессенджерах, без форм и сбора персональных данных.
- каталог новых услуг: подбор мебели, два варианта расстановки, презентация мастера, пакетная упаковка;
- описание работы с объявлениями Avito, сообществами VK, рекламой и визуальными материалами;
- отдельное демонстрационное портфолио интерьеров на `/interiors/`.

## Технологии

Статические HTML, CSS и JavaScript без сборщика и внешних библиотек. Шрифт Manrope хранится локально.

## Локальный запуск

```powershell
python -m http.server 8790
```

После запуска сайт доступен по адресу `http://127.0.0.1:8790/`.
