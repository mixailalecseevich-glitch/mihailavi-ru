# Михаил Косорубов: сайты, Avito, VK и реклама

Персональный одностраничный сайт Михаила. Показывает услуги, реальный кейс «Кело. Северный дом» и ведет посетителя напрямую в сообщения VK или Telegram.

## Что есть на сайте

- сайт под ключ;
- ведение и оформление Avito;
- оформление сообществ и реклама VK;
- аудит интернет-упаковки;
- кейс со скриншотами сайта, сообщества и рекламного кабинета;
- адаптивные версии для компьютера и телефона;
- только прямые контакты в мессенджерах, без форм и сбора персональных данных.

## Технологии

Статические HTML, CSS и JavaScript без сборщика и внешних библиотек. Шрифт Manrope хранится локально.

## Локальный запуск

```powershell
python -m http.server 8790
```

После запуска сайт доступен по адресу `http://127.0.0.1:8790/`.
