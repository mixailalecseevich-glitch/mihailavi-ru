# DESIGN.md — Михаил Ави / Портфолио Авитолога

## 1. Objective

Сайт должен вызывать доверие у владельцев бизнеса, которые ищут специалиста по продвижению на Авито. После просмотра посетитель должен понимать: «Этот человек знает своё дело, у него есть результаты, с ним можно работать». Качество — экспертность без заносчивости.

## 2. Product Context

- **What the product does:** Помогает бизнесу получать больше заявок и продаж через Авито — упаковка профиля, ведение рекламы, стратегия продвижения.
- **Who it's for:** Владельцы малого и среднего бизнеса, которые продают услуги или товары на Авито и хотят увеличить поток клиентов.
- **Adjacent brands (feel like these):** Ramp (чистая типографика), Linear (строгость и ясность), Stripe (доверие через细节).
- **Distant brand (do not feel like this):** Typical freelancer template on Tilda — шаблонность, нет индивидуальности.
- **Cultural register:** Серьёзный, но не холодный. Экспертный, но доступный.

## 3. Visual Foundations

### 3a. Color

- **Neutral scale:** `--n-50: #FAFAFA, --n-100: #F5F5F5, --n-200: #E5E5E5, --n-300: #D4D4D4, --n-400: #A3A3A3, --n-500: #737373, --n-600: #525252, --n-700: #404040, --n-800: #262626, --n-900: #171717, --n-950: #0A0A0A`
- **Accent(s):** `--accent: #10B981` (emerald-500 — зелёный Авито, но приглушённый)
- **Usage rules:** Акцент используется для CTA-кнопок, ссылок и одной ключевой цифры на экране. Никогда как фон секции.

### 3b. Typography

- **Display face:** Inter, 700 weight, tight tracking (-0.02em)
- **Body face:** Inter, 400/500 weight
- **Fallback stack:** `Inter, -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif`
- **Type scale:** 14 / 16 / 18 / 20 / 24 / 32 / 40 / 56 / 72
- **Weight discipline:** 700 — только заголовки h1-h3. 500 — акценты, кнопки, навигация. 400 — основной текст.

### 3c. Spacing & rhythm

- **Base unit:** 8px
- **Spacing scale:** 4, 8, 16, 24, 32, 48, 64, 96, 128 px
- **Section padding:** ≥ 96px на десктопе, ≥ 64px на мобильном

### 3d. Component seeds

- **Button:** 2 варианта — filled (акцент) и ghost (прозрачный с бордером). Радиус 8px. Высота 48px.
- **Card:** Без тени, с тонким бордером `1px solid var(--n-200)`, радиус 12px. Hover: бордер становится акцентным.
- **Iconography:** Lucide Icons, stroke 1.5px, размер 24px.

## 4. Accessibility

- **Text contrast:** body 4.5:1 min, large text/UI 3:1 min
- **Motion:** prefers-reduced-motion: все анимации отключены
- **Focus indicators:** 2px outline accent color, offset 2px
- **Alt text policy:** декоративные — пустые, информативные — описательные

## 5. Voice & Tone

- **Register:** Разговорный экспертный — «ты» к читателю, без канцелярита
- **Sentence rhythm:** Короткие предложения. Один абзац = одна мысль.
- **Words this brand uses:** результат, заявка, продажа, стратегия, рост
- **Words this brand refuses:** уникальный, передовой, синергия, инновационный, комплексный
- **Address:** «ты» / «ваш бизнес»

## 6. Implementation Practices

- **Token format:** CSS custom properties
- **Component library:** Bespoke (чистый HTML/CSS/JS без фреймворков)
- **Image treatment:** Нет фоторафий — сайт строится на типографике и данных. Если фото — то реальные, не стоковые.
- **Grid system:** 12-колоночная сетка, max-width 1200px
- **Motion rules:** ease-out, 200-300ms, только hover-состояния и плавная прокрутка

## 7. Anti-Patterns

- **No gradient hero.** Hero-секция — это большая типографика и конкретное предложение, не декоративный фон.
- **No emoji in headers.** Заголовки — чистый текст. Визуальные якоря — через типографику и цвет.
- **No card grid of features.** Услуги presented как typographic sections с detail, не как иконки в коробках.
- **No "seamlessly" or "elevate".** Каждое предложение говорит о конкретном результате.
- **No auto-scrolling testimonial carousel.** Отзывы — статичные, с именами и компаниями.

## 8. Decision-Making

1. **Ясность > Красота.** Если красивый элемент мешает понять предложение — убрать.
2. **Конкретика > Абстракция.** «+47% заявок» лучше «увеличение эффективности».
3. **Доверие > Демонстрация.** Не показывать «я крутой», а показывать результаты клиентов.
4. **Простота > Навороченность.** Меньше анимаций, меньше слоёв, меньше визуального шума.
5. **Мобильный > Десктоп.** 80%+ трафика Авито — мобильные. Сначала проектируем для телефона.

## 9. Workflow

1. Определить структуру страниц и навигацию
2. Создать DESIGN.md и утвердить направление
3. Развернуть HTML-каркас с semantic markup
4. Наполнить контентом по секциям
5. Добавить CSS (custom properties → компоненты → адаптив)
6. Добавить JS (навигация, мобильное меню, плавная прокрутка)
7. Проверить доступность и адаптивность
8. Задеплоить на GitHub Pages
