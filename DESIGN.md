# DESIGN.md: Михаил / digital-специалист

## 1. Objective

Сайт должен вызывать доверие у владельцев малого бизнеса, частных мастеров и людей, которым нужны интерьерные идеи. После просмотра посетитель понимает, кто выполняет работу, что входит в конкретную услугу, какие материалы нужны и куда написать.

## 2. Product Context

- **Продукт:** персональное портфолио с каталогом услуг, интерьерными примерами, кейсами и прямыми контактами.
- **Аудитория:** владельцы малого бизнеса, частные специалисты и заказчики интерьерных визуализаций.
- **Впечатление:** профессионально, живо, понятно, без агентского пафоса.
- **Антиориентир:** типовой шаблон фрилансера со стоковыми фотографиями и неподтвержденными обещаниями.

## 3. Visual Foundations

### 3a. Color

- **Основа:** темный графитовый `#101318`, светлый холодный фон `#eef1f4`.
- **Акцент:** оранжевый `#e66f3e`, сохраняющий преемственность сайта и перекликающийся с кирпичной локацией нового главного фото.
- **Правило:** акцент используется для действий, маркеров и отдельных слов, а не для заливки целых секций.

### 3b. Typography

- **Шрифт:** Manrope, локальные файлы 400/500/600/700/800.
- **Иерархия:** крупный короткий заголовок, спокойный основной текст, небольшие служебные подписи.
- **Резервный стек:** `Arial, sans-serif`.

### 3c. Spacing & rhythm

- **Базовый шаг:** 8px.
- **Ритм:** свободный на компьютере, компактный на телефоне.
- **Максимальная ширина:** 1180px.

### 3d. Component seeds

- **Кнопки:** основная оранжевая и вторичная контурная, высота не меньше 48px.
- **Карточки:** тонкая граница, радиус 14px, без тяжелых теней.
- **Иконки:** единое семейство Tabler Icons, файлы хранятся локально.

## 4. Accessibility

- **Text contrast:** body 4.5:1 min, large text/UI 3:1 min
- **Motion:** prefers-reduced-motion: все анимации отключены
- **Focus indicators:** 2px outline accent color, offset 2px
- **Alt text policy:** декоративные — пустые, информативные — описательные

## 5. Voice & Tone

- **Регистр:** разговорный экспертный, без канцелярита
- **Sentence rhythm:** Короткие предложения. Один абзац = одна мысль.
- **Основные слова:** сайт, объявление, сообщество, реклама, запуск, результат.
- **Не используем:** уникальный, передовой, синергия, гарантированные заявки.
- **Обращение:** нейтральное, без давления.

## 6. Implementation Practices

- **Token format:** CSS custom properties
- **Component library:** Bespoke (чистый HTML/CSS/JS без фреймворков)
- **Фотографии:** главный портрет основан на фотографии Михаила и отредактирован с помощью ИИ по утверждённому им варианту; клиентские кейсы показываются только с подтверждёнными материалами. Демонстрационные интерьерные визуализации не называются реализованными ремонтами.
- **Сетка:** адаптивная, максимальная ширина 1180px.
- **Motion rules:** ease-out, 200-300ms, только hover-состояния и плавная прокрутка

## 7. Anti-Patterns

- **No gradient hero.** Hero-секция — это большая типографика и конкретное предложение, не декоративный фон.
- **No emoji in headers.** Заголовки — чистый текст. Визуальные якоря — через типографику и цвет.
- **No card grid of features.** Услуги presented как typographic sections с detail, не как иконки в коробках.
- **No "seamlessly" or "elevate".** Каждое предложение говорит о конкретном результате.
- **No auto-scrolling testimonial carousel.** Отзывы — статичные, с именами и компаниями.

## 8. Decision-Making

1. **Ясность > Красота.** Если красивый элемент мешает понять предложение — убрать.
2. **Конкретика > Абстракция.** Показываем реальную работу и подтвержденные данные.
3. **Доверие > Демонстрация.** Не показывать «я крутой», а показывать результаты клиентов.
4. **Простота > Навороченность.** Меньше анимаций, меньше слоёв, меньше визуального шума.
5. **Мобильный > Десктоп.** 80%+ трафика Авито — мобильные. Сначала проектируем для телефона.

## 9. Workflow

1. Определить структуру страниц и навигацию
2. Создать DESIGN.md и утвердить направление
3. Развернуть HTML-каркас с semantic markup
4. Наполнить контентом по секциям
5. Добавить CSS (custom properties → компоненты → адаптив)
6. Добавить JS (навигация, мобильное меню, плавная прокрутка)
7. Проверить доступность и адаптивность
8. Задеплоить на GitHub Pages
